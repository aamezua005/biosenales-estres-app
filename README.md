# Aplicación web de detección de estrés mediante bioseñales

Proyecto orientado a la monitorización del estado fisiológico de los usuarios a partir de bioseñales, con el objetivo de detectar situaciones de estrés y generar avisos o recomendaciones.

## Funcionalidades
- Recepción de datos de bioseñales
- Detección de estrés
- Registro de eventos

## Objetivo
Servir como base para aplicar conceptos de contenedores, métricas, logs y observabilidad..
